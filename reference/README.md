# reference

Documentation externe : datasheets, schémas de synthés existants, notes de
mesure. Rien ici n'est de la conception maison — c'est la matière première.

| Dossier | Contenu |
|---|---|
| `datasheets/` | AS3310/3320/3330/3340, LM13700, TL07x, VCA2164, AD5628, tuning AS3340 |
| `kobol/` | RSF Kobol Expander : schémas d'origine, cartes VCO / embase / noise-LFO, brochage P1 (`Plug.txt`) |
| `analog-synth/` | Schémas de référence : MS-20, SH-101 (dont le manuel de service), Pro-One CEM3320, wavefolder JH, VCA, générateur de bruit, hard sync, state-variable filter |

`analog-synth/missing.txt` liste des valeurs de résistances manquantes lors
d'un montage — à recouper avec le schéma concerné avant commande.
