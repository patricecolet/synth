# experiments

Bancs d'essai autonomes, hors de tout projet de carte. Utiles comme point de
départ ou comme preuve qu'un composant fonctionne.

| Dossier | Quoi |
|---|---|
| `DAC_MPC4822/` | Sortie de tables d'ondes sur DAC MCP4822 (SPI, 12 bits, 2 canaux) — ancêtre du firmware PS-101 |
| `DAC_MPC4921/` | Même chose sur MCP4921 (1 canal). Photo du montage : `plaindds_mcp4921_a.jpg` |
| `MCP4822/` | Variante minimale du test MCP4822 |
| `TCL5940/` | Driver PWM 16 canaux TLC5940 — envisagé pour les paramètres secondaires du Kobol |
| `ArduinoDualLFO-master.zip` | Bibliothèque tierce, LFO double (non dézippée d'origine) |
